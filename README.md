# Basic-Cpp
Contains labs done in C++ based on the book Starting Out with C++, 9th Edition, Tony Gaddis, Pearson.

## Labs
* Utilized `structs` to manage and organize inventory within the program 🗃️ (Lab 1)
* Utilized `file` input methods to efficiently retrieve and process data ♻️ (Lab 4)
* Utilized multiple files to `modularize` and manage different components of the program 📦️ (Lab 5)
* Utilized file input methods to efficiently retrieve and process data using `vector` 📝 (Lab 7)
* Developed a program to create and manage a linked list using C++ STL list container 🧵 (Lab 10)
